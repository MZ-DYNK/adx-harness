---
description: 오늘 작업을 정리해 서머리로 보여주고, 필요하면 NOW를 갱신한다
argument-hint: (없으면 오늘)
allowed-tools: Bash(./harness:*), Bash(python3:*), Read, Edit
---

1. `./harness digest` 를 실행한다. 기록된 턴이 없으면 그 사실만 알리고 끝낸다.
2. 결과를 사람이 읽는 순서로 다시 정리한다.
   - 오늘 실제로 결정된 것
   - 아직 열려 있는 것
   - 다음에 이어서 할 것
   질문 목록을 그대로 나열하지 말고 주제 단위로 묶어라.
3. `.harness/NOW.md` 를 읽고, 목표·진행 상태·막힌 점·다음 행동 중
   **실제로 달라진 항목만** 골라 수정안을 제시한다.
   달라진 것이 없으면 갱신하지 않는다고 말하고 끝낸다.
4. 사용자가 승인하면 해당 줄만 고친다. 문서를 다시 쓰지 마라.
5. 검증된 판단 규칙이 새로 생겼을 때만 WIKI·MARKETING·DESIGN 승격을 제안한다.
   근거가 한 번의 관찰뿐이면 승격하지 말고 다음 확인 조건을 남긴다.

하네스 실행 경로는 아래 순서로 찾는다.

1. 현재 디렉터리에 `./harness` 가 있으면 그것을 쓴다.
2. 없으면 `python3 "$CLAUDE_PLUGIN_ROOT/scripts/harness.py"` 를 쓴다.
3. 둘 다 없으면 `claude plugin list` 로 설치 경로를 확인해 알려주고 멈춘다.
