# 프로젝트 위키

검증되었거나 사용자가 수용한 장기 지식의 홈입니다. 짧을 때는 이 파일에
직접 기록하고, 독립적으로 반복 참조할 주제만 `wiki/` 아래 상세 페이지로
분리한 뒤 이곳에서 연결합니다.

## 상세 문서 색인

- 결정: `wiki/decisions/`
- 실행 방법론: `wiki/playbooks/`
- 개념과 용어: `wiki/concepts/`

상세 페이지가 생기기 전에는 디렉터리를 만들 필요가 없습니다.

## 분리 기준

다음 중 하나일 때만 상세 페이지로 분리합니다.

- 이 파일이 500줄을 넘어 탐색이 느려짐
- 한 주제가 독립적으로 반복 참조됨
- 주제마다 담당자나 변경 주기가 다름

분리한 뒤에는 원문을 중복 복사하지 않고 이 색인에 링크와 한 줄 설명을 남깁니다.
