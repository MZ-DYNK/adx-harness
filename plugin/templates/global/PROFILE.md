# 사용자 프로필

이 파일은 사용자 한 명의 정본입니다. 첫 세션에 이 템플릿으로 생성되고, 이후
사용자가 직접 고치거나 하네스가 반복 관찰로 채웁니다.

## 확정된 맥락

- 기본 언어: 한국어
- 역할 수준: 미확인. 첫 작업에서 확인하거나 사용자가 직접 적습니다
- 필요한 범위: 미확인. 코드 위주인지, 기획·마케팅·문서까지인지 확인합니다
- 작업 선호: 복잡한 명령이나 의식적인 워크플로 없이 자동으로 작동
- 위임 선호: 반복 작업과 독립적인 리서치에는 서브에이전트를 적극 활용

## 응답 기준

- 결론과 추천안을 먼저 제시
- 왜 중요한지와 다음 행동을 연결
- 전문 용어는 정확성을 유지하되, 낯선 저수준 개념만 첫 등장에 짧게 설명
- 초급자용 사전식 설명, 같은 말 반복, 불필요한 서론은 생략
- 선택지가 많아도 권장안을 명확히 표시
- 결과를 바꾸지 않는 모호함은 합리적인 기본값으로 진행

## 확정된 선호

- 사용 환경은 Claude Code를 기준으로 설계

## 관찰 중인 선호

- 아직 없음

## 첫 세션에 확인할 것

아래는 사람마다 다릅니다. 확인되기 전에는 사실처럼 쓰지 않습니다.

- 주로 하는 업무와 산출물의 종류
- 설명을 어느 수준까지 풀어야 하는지 (도메인별로 다를 수 있음)
- 업무 아카이브 조사에서 본인 발화만 볼지, 관련자 관점까지 볼지
- 성과 리포트를 요약본으로 볼지, RAW·원본까지 확인할지

## 갱신 규칙

- 사용자가 명시한 선호는 `확정된 선호`로 기록
- 행동에서 추론한 선호는 `관찰 중인 선호`로 기록
- 같은 선호가 반복 확인되기 전에는 관찰을 확정으로 승격하지 않음
- 민감한 개인정보와 계정 정보는 기록하지 않음
- 다른 사람의 프로필을 이 파일로 옮기지 않습니다
