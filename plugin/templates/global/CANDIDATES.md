# 전역 승격 후보

프로젝트에서 관찰한 것 중 전역으로 올릴 만한 후보를 모아 둡니다. 이 파일에
있다는 것은 후보라는 뜻이고, 승격은 사용자 승인 뒤에만 일어납니다.

`./harness promote` 가 게이트 통과 여부를 계산하고, `/promote` 가 검토를
진행합니다. 상태 화면에 대기 건수가 표시됩니다.

## 목적지

| 분류 | 올라가는 곳 | 예 |
|---|---|---|
| 프로필 | `PROFILE.md` | 역할, 응답 선호, 일하는 방식 |
| 취향 | `DESIGN-TASTE.md` | 색·타이포·레이아웃·구성 선호 |
| 방법론 | 해당 스킬의 레퍼런스 | 재사용 가능한 판단 규칙 |

프로젝트 고유 사실, 클라이언트 수치, 계약·시점에 묶인 정보는 후보가 아닙니다.
그것은 프로젝트 정본이나 `imports` 에 남습니다.

## 게이트

- 사용자가 명시한 선호는 관찰 1회로 통과합니다
- 그렇지 않으면 관찰 3회 이상, 서로 다른 프로젝트 2곳 이상, 최초와 최근 관찰
  사이 7일 이상이 필요합니다. 한 세션에서 세 번 본 것은 반복이 아닙니다
- 개인정보, 금액, 토큰, 연락처가 들어 있으면 통과하지 못합니다
- 목표 파일이 크기 상한을 넘으면 먼저 정리해야 합니다

## 후보

아래 형식으로 추가합니다. `관찰` 줄은 하나씩 쌓습니다.

```text
### 한 줄 제목
- 분류: 프로필 | 취향 | 방법론
- 상태: 대기 | 승격 | 보류 | 기각
- 사용자 명시: 예 | 아니오
- 목표: PROFILE.md | DESIGN-TASTE.md | skills/<이름>/references/<파일>
- 관찰: 2026-01-01 / 프로젝트이름 / 무엇을 보고 그렇게 판단했는지
```
