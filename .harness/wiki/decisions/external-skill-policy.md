# 외부 스킬 도입 정책

- 상태: 채택
- 결정일: 2026-07-29
- 적용 범위: Personal Harness와 Claude Code 프로젝트

## 결정

외부 스킬은 `로컬 중복 확인 → 검색 → 원문·권한 검사 → 범위 선택 → 명시 승인`
순서로 도입합니다. 검색 순위와 설치 수는 후보 발견 신호일 뿐 안전성·적합성의
증거로 사용하지 않습니다.

## 기본 범위

- 일회성 사용: 원문·권한 검토와 승인 뒤 가능하면 `npx skills use`
- 특정 프로젝트에서 반복: project scope, Claude Code만 대상으로 복사
- 여러 프로젝트에서 반복: 사용자 승인 뒤 global scope
- Personal Harness 정식 편입: `skills/`에 검토본을 넣고 라우터·테스트·문서까지 갱신

`--all`, wildcard, 검토 없는 global `-g -y` 설치는 기본값으로 사용하지 않습니다.

## 검사 항목

- 정확한 저장소·스킬 경로·확인일·라이선스
- 가능하면 안정된 revision 또는 content hash
- 기존 스킬과의 역할 중복
- 스크립트, 훅, 바이너리, symlink, 외부 의존성
- 파일·네트워크·계정·비밀값 접근 범위
- 삭제, 발송, 배포, 게시 등 외부 상태 변경
- 유지보수 상태와 실제 출력 검증 가능성
- 명령·설정 키·API 예시가 현재 공식 문서와 호환되는지 표본 검증
- 공개 보안 감사와 확인일. 감사 부재는 안전이 아니라 미확인으로 처리

## 거부·보류 기준

- 비밀값 노출이나 안전장치 해제를 요구
- 불필요하게 넓은 권한 또는 관련 없는 의존성 포함
- 검토하기 어려운 실행 파일·훅 포함
- 안정된 원본이나 호환 가능한 라이선스 부재
- 기존 스킬로 충분한데 이름만 다른 중복
