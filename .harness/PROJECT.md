# Personal Harness

## 한 줄 설명

Claude Code를 개발·기획·마케팅·문서·프론트 디자인 전반의 개인 실무
코파일럿으로 사용하는 경량 하네스입니다.

## 목표

- 사용자의 혼합형 실무 수준과 한국어 문체에 자동으로 맞춤
- 한국 시장의 브랜드·광고·디지털·CRM 판단을 한 체계로 연결
- 프로젝트 정본, 일일 대화 기록, 원본 근거를 분리해 장기 기억 구축
- 반복 리서치와 분류는 서브에이전트에 위임하되 최종 판단은 메인 에이전트가 수행
- 프론트 작업에서 디자인·컴포넌트 아이디어와 선택 이력을 축적

## 대상 사용자

- 비개발자·기획자·PM/PO·개발자·마케터의 경계를 오가는 실무형 제너럴리스트
- 복잡한 명령이나 의식적인 지식 관리 없이 Claude Code를 범용적으로 쓰려는 사용자

## 성공 기준

- Claude 플러그인 엄격 검증과 런타임 테스트 통과
- 새 프로젝트에서 `.harness` 정본과 일일 로그가 자동 생성·재참조됨
- 불필요한 전체 아카이브 로딩 없이 현재 상태와 관련 지식만 불러옴
- 토큰·개인정보·제한 원본이 로그나 공유 정본으로 새지 않음
- 마케팅 판단이 플랫폼 지표에서 1st-party·후행 가치까지 연결됨

## 범위와 제약

- 기준 런타임은 Claude Code
- 항상 켜지는 플러그인은 하나로 유지하고 도메인 지식은 조건부 스킬로 로드
- 메일·Slack·첨부 원본은 로컬 `imports`에만 보존하고 기본 문맥·Git에서 제외
- 다른 사람의 발화를 사용자 의견으로 합치지 않고 화자와 근거 수준을 보존
- 클라이언트 수치와 시점성 사실은 전역 지식으로 승격하지 않음

## 주요 자산과 시스템

- `.claude-plugin/`, `hooks/`, `scripts/harness.py`
- `scripts/knowledge.py`: Markdown 기반 SQLite FTS 파생 인덱스
- `scripts/skill_router.py`, `config/skill-routing.json`: 턴별 스킬 후보 라우팅
- `agents/`: 기본 코파일럿, 리서치, 지식 큐레이션 역할
- `skills/`: 적응형 문서, 프론트, 프로젝트 지식, 한국 마케팅과 네 개의
  실행형 마케팅 방법론, 안전한 외부 스킬 탐색
- `templates/`: 전역 프로필과 프로젝트 정본 템플릿
- `.harness/imports/`: 제한 원본과 검증 가능한 조사 요약
- `~/.claude/personal-harness-data/global/`: 통합된 전역 프로필·디자인 취향
